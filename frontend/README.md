# 🟢 Zuckrey EpsLarp — Standalone Web Portal Mirror

This directory contains the standalone frontend application files for **Zuckrey EpsLarp**.

- `index.html`: Main HTML UI shell (Windows 2000 / IE 5.5 Retro Cyberpunk Portal).
- `js/feed.js`: Feed rendering engine with IST timezone conversion & red burgundy card templates.
- `js/game.js`: ZUCK-RUNNER 2D arcade canvas engine (60x60 Raptor, 25x35 Cacti).
- `styles/main.css`: Desktop wallpaper (`assets/img/desktop_bg.png`), CRT overlay & retro styles.
- `assets/img/`: Game sprites, desktop background, and 3D avatar assets.

For full system architecture, backend deployment, API details, and scraper documentation, see the root [`README.md`](../README.md).
